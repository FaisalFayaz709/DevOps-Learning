## Concept already discussed: Apache HTTP Server

Apache HTTP Server is a **web server application**. It can receive HTTP/HTTPS requests and serve website content or proxy traffic to an application.

```text
Browser
   ↓
Apache HTTP Server
   ↓
Website / backend application
```

Common default web ports:

- HTTP: `80`
- HTTPS: `443`

On a Linux system, Apache normally runs in the background as a service after installation, but service-management commands are intentionally not included until I study them.
